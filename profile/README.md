# Locorda

Offline-first sync for Dart/Flutter — BYOB: Google Drive, Solid Pods, or any file storage. Plus the RDF & semantic web libraries that power it.

## Projects

### Ready to Launch

**[🔷 RDF](https://github.com/locorda/rdf)** — Dart libraries for working with RDF data  
**[📚 RDF Vocabularies](https://github.com/locorda/rdf-vocabularies)** — Common RDF vocabularies as Dart packages

### Work in Progress

**[🔄 Sync Engine](https://github.com/locorda/sync-engine)** — Dart library for offline-first sync with passive storage backends (early stage)

**[🌐 Locorda Website](https://github.com/locorda/locorda)** — Project website and documentation
